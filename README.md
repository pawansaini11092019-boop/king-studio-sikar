KING STUDIO SIKAR - Flutter starter project

Included working features:
- Pick photo from gallery or camera
- Brightness and contrast adjustments
- Preview edited image
- Save edited image in app documents storage
- Share edited image

Build on Codemagic:
1. Upload the CONTENTS of this folder to a GitHub repository (not the ZIP itself).
2. Connect the repository to Codemagic.
3. Select Flutter and use codemagic.yaml.
4. Start build; download app-release.apk from build artifacts.

Not yet implemented: crop, filters, blur, collage, text/stickers, AI editing.
No ads, subscriptions or payments are included.
